# 🔥 ForenGuard - AI Powered Cybersecurity System

## 🚀 Overview
ForenGuard is a real-time intrusion detection system that monitors system activity, detects suspicious behavior, and alerts users instantly.

## 🧠 Features
- Real-time file monitoring
- AI-based anomaly detection
- Network threat detection
- Keylogger detection
- CPU anomaly detection
- Alerts system (dashboard + email)
- Admin panel

## 🛠 Tech Stack
- Backend: FastAPI
- Frontend: HTML, CSS, JS
- Database: SQLite
- ML: Isolation Forest

## 📊 What it does
- Detects suspicious files (.exe, .bat)
- Monitors processes
- Detects abnormal system behavior
- Provides real-time alerts

## 🎯 Future Scope
- Cloud monitoring
- Multi-user system
- Mobile app
